# glinven-site

Public source for **[glinven.com](https://glinven.com)** — the marketing site for GLINVEN CORP.

GLINVEN provides IT systems, software development, automation, and technical services for government and commercial organizations.

## Live site

https://glinven.com

## What’s in this repo

| Path | Purpose |
|------|---------|
| `index.html` | Homepage markup |
| `styles.css` | Layout and visual design |
| `app.js` | Menu, hero, and video UI behavior |
| `assets/` | Favicon, OG image, hero video/poster |
| `robots.txt` / `sitemap.xml` | SEO / crawl basics |

Static site — no build step, no package manager.

## Run locally

```bash
# from repo root
python3 -m http.server 8080
# then open http://localhost:8080
```

Or open `index.html` directly in a browser (some video/asset paths work best via a local server).
